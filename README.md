# 課序 · 家教數學題庫公開展示

網站：https://yuleilei0422.github.io/kexu-math-bank/

教師題庫／組卷及作答結果、學生自選姓名／學制／年級／單元自動出卷、作答／紙本介面與示範卷列印。高中／高職數學優先，24題都是自編示範。

這是靜態展示，不提供真實登入、派卷、交卷、附件上傳或後端資料庫。學生完成後自動核對選擇與數值答案，文字解法保留教師複核。學生介面只顯示完成，不顯示分數、對錯或詳解。結果於同一瀏覽器分頁sessionStorage暫存，可在教師結果頁查看，尚未跨裝置回傳。公開展示沒有教師權限保護，請使用示範姓名。完整正式版本仍在本機開發，學校原卷、正式题庫與帳號資料未包含於此庫。

## 發布

GitHub Pages以main分支根目錄發布。所有資產使用相對路徑；無第三方API或CDN。
